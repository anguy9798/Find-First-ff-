# Command Description:
This tool is a fancy keyword searcher that searches for a specific keyword within a file for a specific text pattern. When processed, it returns the number of matching lines within the file alongside the total word count.
To run it, use Node.js by typing node and providing the targeted file that supplies a search pattern.
EX: node ff.js hello randomfile.txt
If "hello" exists in the text file, it returns "Pattern found: hello found in (AMOUNT OF TIMES) lines within randomfile.txt"
The commands that it combines are grep and wc, with grep helping search for a word, while wc finds the number of times the word was discovered
